# ۱. معرفی مسئله، اهداف و دامنه

## مسئله

کلینیک‌های دندان‌پزشکی کوچک معمولاً فرایند نوبت‌دهی را با تلفن و دفترچه انجام می‌دهند. این کار برای بیمار و پذیرش وقت‌گیر است، در رزرو هم‌زمان یک زمان خطا ایجاد می‌کند و اطلاعات بیماران پراکنده و غیرقابل جستجو است. هدف پروژه، ساخت یک **سامانه مدیریت کلینیک** با یک **دستیار هوش مصنوعی عامل‌محور (Agentic AI)** است که بخش عمده کارهای نوبت‌دهی و مشاهده اطلاعات را به زبان طبیعی فارسی انجام دهد، بدون آنکه کنترل نهایی عملیات از دست کارکنان خارج شود.

## اهداف پروژه

1. مدیریت کاربران با احراز هویت امن و نقش‌های `admin`، `receptionist`، `doctor` و `patient`.
2. مدیریت پرونده پایه بیماران (اطلاعاتی که پروپوزال لازم می‌داند، نه پرونده الکترونیک پیشرفته).
3. مدیریت پزشکان و خدمات دندان‌پزشکی و برنامه‌ی زمانی پزشکان.
4. مدیریت کامل چرخه نوبت: مشاهده، جستجوی زمان آزاد، رزرو، لغو و جابه‌جایی با ممنوعیت رزرو هم‌زمان.
5. دستیار عامل‌محور مبتنی بر LangChain/LangGraph که درخواست کاربر را تحلیل می‌کند، از ابزارهای مجاز استفاده می‌کند، در صورت ابهام سؤال می‌پرسد و پیش از هر عملیات حساس تأیید صریح می‌گیرد.
6. وب‌سایت فارسی/راستچین نقش‌محور که فقط با API امن سمت سرور کار می‌کند.
7. امکان اجرای کامل محلی با مدل زبانی محلی (مثل Ollama) یا ارائه‌دهنده‌ی API.

## خارج از دامنه (طبق پروپوزال)

- پرونده الکترونیک پیشرفته، تصویربرداری، نسخه‌نویسی و تشخیص پزشکی.
- درگاه پرداخت و صورتحساب.
- اپ موبایل.
- دستیار پشتیبانی/مدیریتی (Monitor/DevOps/Security) — به‌عنوان توسعه آینده در سند محدودیت‌ها ثبت شده است.

## فناوری‌های استفاده‌شده

| لایه | فناوری |
|---|---|
| Backend | Python + FastAPI (async) |
| پایگاه داده | SQLite (async با aiosqlite) + SQLAlchemy 2.x |
| Agent | LangChain + LangGraph (گراف agent_decision → confirmation_gate → tool_execution) |
| مدل زبانی | Provider-neutral: Ollama (محلی)، OpenAI/OpenRouter-compat؛ انتخاب با متغیر محیطی |
| رابط کاربری | HTML/CSS/JS خالص، فارسی RTL، همان‌مبدأ با backend |
| آزمایش | pytest + unittest، تحلیل DOM با jsdom |
