# Dental Agent — وب‌کلاینت React (هم‌دامنه با FastAPI)

رابط کاربری اصلی سامانه: React 19 + TypeScript + Vite + Tailwind 4، فارسی و چپ‌به‌راست.
FastAPI صفحهٔ ساخته‌شده را در `/app` و فایل‌های static را زیر `/app-assets` سرو می‌کند؛
تمام فراخوانی‌های API نسبی و هم‌دامنه‌اند (بدون CORS).

## ساختار

```
webapp/
├─ index.html              قالب SPA (فونت Vazirmatn)
├─ vite.config.ts          build با base=/app-assets/ ، dev با پروکسی API به :8000
├─ src/api/client.ts       کلاینت واحد HTTP (خطاها با کد وضعیت: ApiError)
├─ src/components/         داشبورد، بیماران، نوبت‌ها، پزشکان، خدمات، چت ایجنت
├─ src/context/            AuthContext (/auth/*) و ClinicContext (داده‌ها)
├─ src/utils/              RBAC، تاریخ جلالی، بررسی تعارض نوبت (+ تست‌های node:test)
└─ dist/                   خروجی build (git-ignored) — FastAPI همین را سرو می‌کند
```

## دستورها

```powershell
npm install        # یک بار
npm run build      # تولید dist (پیش‌فرض پایه: /app-assets/)
npm run dev        # توسعه: پورت 3000 + پروکسی /auth,/agent,... به http://127.0.0.1:8000
npm run test       # ۹ تست منطق (node:test + tsx)
npm run lint       # بررسی tsc --noEmit
```

## نکته‌ها

- آدرس بک‌اند به‌صورت پیش‌فرض «هم‌دامنه» است؛ از «تنظیمات اتصال» داخل اپ می‌توان یک سرور دیگر (مثلاً `http://127.0.0.1:8000`) را موقتاً انتخاب کرد.
- درخواست چت ایجنت بودجهٔ زمانی 300 ثانیه دارد (مدل لوکالِ LM Studio کند پاسخ می‌دهد)؛ سایر درخواست‌ها 6 ثانیه.
- تصویر هیروی داشبورد به‌صورت import محلی bundel می‌شود؛ هیچ کلید یا راز بک‌اندی به مرورگر ارسال نمی‌شود.
- اگر `dist` ساخته نشده باشد، `app/main.py` صفحهٔ قدیمی `web/` را به‌جای `/app` سرو می‌کند (fallback).

## مقیاس تایپی

اندازه‌های متن فقط از این توکن‌ها (در `src/index.css`، بر پایهٔ `rem`) می‌آیند؛ کمینه ۱۲ پیکسل است و از اندازهٔ فونت مرورگر کاربر پیروی می‌کند:

| کلاس | اندازه | کاربرد |
|---|---|---|
| `text-caption` | ۱۲px | زمان، نشان، سرستون جدول، متن راهنما |
| `text-small` | ۱۳px | متن ثانویه، چیپ، سلول جدول، منو |
| `text-body` | ۱۴px | متن اصلی و فیلدهای فرم |
| `text-lead` | ۱۵px | عنوان بخش‌ها و متن تأکیدی |
| `text-heading` | ۱۶px | عنوان کارت و پنجره |

عنوان‌های بزرگ‌تر (۱۷px به بالا) همان‌جا که استفاده می‌شوند تعریف می‌شوند. روی موبایل فیلدهای فرم ۱۶px هستند تا iOS هنگام فوکوس صفحه را زوم نکند. `src/utils/typeScale.test.ts` جلوی برگشت اندازه‌های زیر ۱۲px را می‌گیرد (تنها استثنا: برچسب ماه زیر نمودار روی موبایل، ۱۱px).
