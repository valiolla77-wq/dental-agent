# Dental Agent — دموی دانشگاهی

سامانه مدیریت مطب دندان‌پزشکی با دستیار ایجنت فارسی. بیمار از صفحه چت می‌تواند زمان آزاد را ببیند، درخواست رزرو/لغو/جابه‌جایی بدهد، پیشنهاد را تأیید یا رد کند و نتیجه واقعی را در دیتابیس ببیند.

> این پروژه یک دموی دانشگاهی است. SMS واقعی ارسال نمی‌شود و رمزهای نمونه فقط برای دمو هستند. هرگز از دیتابیس Production یا بکاپ واقعی برای این دمو استفاده نکنید.

## پیش‌نیازها

- Python 3.11
- دسترسی به یک سرویس LLM سازگار با OpenAI (در دموی فعلی: 9router روی `http://localhost:20128/v1`)
- مدل تنظیم‌شده در `.env` (نمونه: `cx/gpt-6-luna`)

## ۱. نصب

از ریشه پروژه:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## ۲. تنظیمات محیطی

فایل `.env.example` را به `.env` کپی کنید و مقادیر را در همان فایل محلی تنظیم کنید. `.env` در `.gitignore` است و نباید Commit شود.

حداقل متغیرهای لازم:

```dotenv
DATABASE_URL=sqlite+aiosqlite:///./demo.db
JWT_SECRET=<یک مقدار تصادفی طولانی و محرمانه>
CONFIRMATION_HMAC_SECRET=<یک مقدار تصادفی مستقل و محرمانه>
APP_ENV=development
OTP_PROVIDER=fake

AGENT_LLM_PROVIDER=openai
AGENT_LLM_MODEL=cx/gpt-6-luna
AGENT_LLM_BASE_URL=http://localhost:20128/v1
AGENT_LLM_TEMPERATURE=0
AGENT_LLM_API_KEY=<کلید محلی؛ فقط در .env>
```

نکات:

- `JWT_SECRET` و `CONFIRMATION_HMAC_SECRET` را از هم جدا نگه دارید.
- کلید API مدل فقط سمت سرور و در `.env` محلی است؛ در مرورگر یا مخزن قرار نمی‌گیرد.
- برای Providerهای دیگر، `AGENT_LLM_PROVIDER=ollama` یا `openrouter` و متغیر مربوط به کلید همان Provider را مطابق `.env.example` تنظیم کنید.
- `APP_ENV=development` و `OTP_PROVIDER=fake` باعث می‌شوند کد OTP آزمایشی در پاسخ API برگردد. در Production این قابلیت غیرفعال است.

## ۳. اجرای LLM محلی

سرویس LLM محلی را قبل از FastAPI اجرا کنید و مطمئن شوید مدل تنظیم‌شده در دسترس است. مثلاً برای 9router:

```powershell
# سرویس 9router باید روی پورت 20128 در حال اجرا باشد.
curl.exe http://localhost:20128/v1/models
```

اگر سرویس در دسترس نباشد، صفحه چت کار می‌کند اما پاسخ Agent خطای قابل‌فهم دریافت می‌کند. هیچ درخواست مدل از مرورگر ارسال نمی‌شود؛ همه از بک‌اند عبور می‌کنند.

## ۴. ساخت دیتابیس دمو و داده‌های آزمایشی

از ریشه پروژه و در همان ترمینالی که `DATABASE_URL` را تنظیم کرده‌اید:

```powershell
$env:DATABASE_URL = "sqlite+aiosqlite:///./demo.db"
$env:PYTHONIOENCODING = "utf-8"
.\.venv\Scripts\python.exe -m scripts.seed_demo
```

Seed Script:

- فقط وقتی اجرا می‌شود که `DATABASE_URL` دقیقاً به `demo.db` در ریشه پروژه اشاره کند.
- Idempotent است؛ اجرای دوباره رکورد تکراری نمی‌سازد.
- هیچ دیتابیس موجودی را حذف، خالی یا Reset نمی‌کند.
- قبل از هر اتصال، مقصد را اعتبارسنجی می‌کند.

داده‌های ساختگی:

| مورد | مقدار |
|---|---|
| مدیر | `09120000001` / `DemoAdmin!123` — فقط دمو |
| بیمار | `09120000002` — ورود با OTP آزمایشی |
| پزشکان | دکتر سارا احمدی و دکتر امیر کریمی |
| خدمات | معاینه اولیه دندانپزشکی، ترمیم دندان، جرم‌گیری نمایشی |
| برنامه کاری | همه روزهای هفته، ۰۹:۰۰ تا ۱۳:۰۰، Slotهای ۳۰ دقیقه‌ای برای هر دو پزشک |

**رمزها و شماره‌های بالا صرفاً داده ساختگی دمو هستند و نباید در Production استفاده شوند.**

## ۵. اجرای FastAPI و صفحه چت

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

- صفحه چت بیمار: **http://127.0.0.1:8000/demo**
- Swagger (برای مدیر/مدیریت): **http://127.0.0.1:8000/docs**
- Health: **http://127.0.0.1:8000/health**

## ۶. سناریوی ورود و دمو

### ورود بیمار از صفحه چت

1. آدرس `/demo` را باز کنید.
2. شماره `09120000002` را وارد کنید.
3. «دریافت کد آزمایشی» را بزنید. چون `APP_ENV=development` و `OTP_PROVIDER=fake` است، کد در کادر مخصوص دمو نمایش داده و خودکار پر می‌شود.
4. «ورود به گفت‌وگو» را بزنید.
5. یکی از درخواست‌های نمونه را بنویسید؛ مثلاً:
   > نزدیک‌ترین نوبت برای جرم‌گیری نمایشی را پیدا کن.
   یا:
   > دندونم پوسیده، چه خدمتی دارید؟ نزدیک‌ترین نوبت معاینه را بده.
6. ایجنت ابتدا خدمات/پزشکان/Slotها را از دیتابیس بررسی می‌کند و پیشنهاد رزرو را نمایش می‌دهد؛ تا زدن «تأیید و انجام» هیچ نوبتی ثبت نمی‌شود.
7. با «تأیید و انجام» یا «رد درخواست»، نتیجه واقعی نمایش داده می‌شود.
8. «گفت‌وگوی جدید» شناسه نشست، تاریخچه محلی و تأیید قبلی را پاک می‌کند.

### ورود مدیر

از Swagger در `/docs`:

- `POST /auth/login` با شماره `09120000001` و رمز `DemoAdmin!123`.
- توکن را در دکمه Authorize وارد کنید.
- ساخت بیمار/پزشک/خدمت/برنامه کاری و اتصال بیمار به حساب از همان Swagger انجام می‌شود. Seed Script داده‌های اصلی را از قبل ساخته است.

> برای نمایش مدیریت، Swagger کافی است؛ در این مرحله داشبورد گرافیکی مدیریت اضافه نشده است.

## ۷. تست‌ها

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

تست‌ها از دیتابیس موقت استفاده می‌کنند و به LLM یا SMS خارجی وابسته نیستند.

## محدودیت‌های دمو

- SMS واقعی غیرفعال است؛ فقط Provider Fake توسعه فعال است.
- صفحه چت یک صفحه دمو است، نه داشبورد کامل مدیریت.
- تاریخچه گفت‌وگو در سرور ذخیره نمی‌شود؛ فقط Confirmation پایدار است.
- سرویس LLM محلی باید در دسترس باشد؛ کلید API نباید در مرورگر یا Git قرار گیرد.
- اگر CORS لازم شد (Frontend جداگانه)، باید صریحاً در FastAPI تنظیم شود؛ صفحه `/demo` روی همان Origin است و CORS لازم ندارد.
